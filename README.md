# Curso de Servicios Web Geográficos

Repositorio personal para el desarrollo de los talleres de Servicios Web Geográficos.

## Información del proyecto

- **Estudiante:** Roger Viasus
- **Área:** Sistemas de Información Geográfica (SIG)
- **Herramientas:** Git, GitHub, Python, QGIS, PostgreSQL/PostGIS, GeoServer, Docker y Leaflet.

## Objetivo

Desarrollar las actividades de nivelación y los talleres prácticos del curso, aplicando herramientas de gestión de datos espaciales, servicios web geográficos y visualización cartográfica.

## Avances

- Ejercicio A1: Sistema, archivos y terminal — completado.
- Ejercicio A2: Git y control de versiones — en desarrollo.

## Datos geográficos

El repositorio incluye información geográfica de hospitales del departamento de Boyacá en formato GeoJSON.
